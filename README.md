# sirco-validator MVP

## Avvio
- `npm install`
- `npm run dev`
- Apri `http://localhost:3000`

## Input file
Metti i file TXT fixed-length in `data/input`:
- `A.txt`
- `B.txt`
- `C.txt`
- `D.txt`
- `E.txt`
- `F.txt`
- `G.txt`

L'app legge i file localmente lato server (senza upload, senza database).
